# 🎬 Кинопоиск — Модуль рекомендательной системы (Прототип)

Демонстрационный прототип интерфейса онлайн-кинотеатра с интегрированным модулем персональных рекомендаций. Разработан в рамках курсовой работы по проектированию рекомендательных систем.

## 📌 О проекте
Проект представляет собой SPA (Single Page Application) на чистом HTML, CSS и JavaScript. Основная задача — визуализировать работу гибридного алгоритма рекомендаций и показать удобный пользовательский интерфейс для взаимодействия с каталогом фильмов.

### ✨ Основные возможности:
*   **Умный поиск** по названию, жанру и году выпуска.
*   **Динамический баннер** с персональной рекомендацией.
*   **Запуск трейлеров** (интеграция HTML5 Video).
*   **Избранное** (сохранение списка фильмов в `localStorage` браузера).
*   **Уведомления (Колокольчик)** — система клиентских пуш-уведомлений, которая реагирует на авторизацию и добавление фильмов в избранное.
*   **Авторизация и регистрация** (имитация с сохранением сессии в `localStorage`).
*   **Адаптивный дизайн** (корректно отображается на ПК, планшетах и смартфонах).

## 🧠 Рекомендательная система (Теория)
В проекте реализована имитация выдачи рекомендаций на основе гибридного подхода. В интерфейсе предусмотрена таблица с метриками эффективности:

| Модель | NDCG@10 | HitRate@10 | Cold-start | Latency p95 |
| :--- | :--- | :--- | :--- | :--- |
| Коллаборативная (Matrix Factorization) | 0.71 | 0.58 | Слабо | 35 мс |
| Контентная (BERT embeddings) | 0.69 | 0.55 | Хорошо | 28 мс |
| **Гибридная (наша)** | **0.78** | **0.64** | **Хорошо** | **42 мс** |

*Используется гибридный алгоритм: коллаборативная фильтрация + контентные эмбеддинги (на основе жанров и описаний).*

## 🛠 Технологический стек
*   **Frontend:** HTML5, CSS3 (Flexbox, Grid, CSS-переменные), Vanilla JavaScript (ES6+).
*   **Хранение данных:** `localStorage` (сессия пользователя, список избранного).
*   **Медиа:** HTML5 `<video>` (воспроизведение локальных MP4-файлов).
